UrbanLake connects a reproducible local data pipeline to a lightweight analytics application. The hosted API serves verified aggregate data and the trained model. The full request archive and processing services stay on the local machine.

Local data platform · manual runs
01 · SOURCE
NYC 311 API

Bounded monthly extraction with source-count reconciliation.

02 · ARCHIVE
Immutable pages

Compressed records, checksums, and resumable manifests.

03 · TRANSPORT
Apache Kafka

Acknowledged relay and stable observation identities.

04 · LAKEHOUSE
Spark + Delta

Bronze observations, current Silver keys, and Gold metrics.

05 · ORCHESTRATION
Apache Airflow

Manual DAGs; scheduling remains disabled.

06 · TRAINING
MLflow + model

Chronological evaluation, audit gates, tracked artifact.

Local Redis supports the local API cache. The hosted app does not expose Docker controls, raw records, Kafka, Airflow, or local monitoring services.

Respect time and source limits

The partial latest source day is excluded from training. A stale source stays visible, and the API accepts only its supported target date.

Keep the boundary clear

The hosted analytics use aggregates. Kafka, Spark, Delta, Airflow, MLflow, and raw request storage remain on the local platform.
